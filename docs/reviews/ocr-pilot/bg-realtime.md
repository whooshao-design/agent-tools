# 评审背景：实时运营应用本地执行表达式规则（与策略决策应用解耦）

目标：server_rc_realtime_operation 不再远程调用 server_strategy_decision_java 判定事件规则，而是在本地用 QLExpress 执行规则；通过三态开关（local / remote / shadow）切换，shadow 模式两侧都执行并比对结果，保留远程判定作为最终结果。

本次变更范围（7 个文件）：pom.xml 显式声明发布接口包依赖并排除传递依赖；CommonConfig 读取执行模式配置；新增 RuleExecuteMode 枚举；ExpressRuleOperateLogicService 按模式分流；新增 LocalExpressRuleExecutor（线程池 8 线程、队列 16，单次等待 3000ms，超时取消并移除排队任务）；两个测试类。

验收标准：
- AC-001 代码与配置中不再存在对 server_strategy_decision_java 的引用，仅为该调用存在的依赖已移除。
- AC-002 被依赖应用不可用时，本应用可正常启动并正常完成事件规则判定。
- AC-003 并行比对期内不一致数可观测（打点或日志），收敛到 0 后由研发切换开关。
- AC-004 切换后事件命中与不命中行为回归通过，下游流程触发正常。
- AC-005 开关可在线切回原方式并立即生效。
- AC-006 异常规则不会导致消息消费阻塞，单次判定耗时受上限保护。

用户已决定并保留的取舍（不要作为问题报告）：三态显式执行；shadow 保留远程判定；toString 比较时保留 null；差异详情记录双方结果与异常；撤回保存时的语法限制；删除永久熔断，仅保留本地 3 秒等待；RPC 参数类型疑点留待线上 shadow 观察。

重点关注：模式缺失/非法/读取异常时是否回退 remote；参数浅拷贝共享嵌套对象的副作用边界；线程池满与超时路径的资源释放；异常是否会阻塞 MQ 消费；日志与指标是否隔离异常。
