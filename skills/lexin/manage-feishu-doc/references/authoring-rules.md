# 飞书文档的写作与排版

`S=/home/joney/projects/ai/agent-tools/skills/lexin/manage-feishu-doc/scripts/feishu_doc.mjs`

适用于发布到飞书的三类文档：技术方案、操作/指导手册、资料与参考文档。技术方案的结构按 dev-design-solution 的模板，本文不重复规定，只补飞书侧的排版。规则来源见 `~/docs/requirements-development/feishu-doc-skill-optimization/research/04-content-authoring.md`（官方帮助中心、larksuite/cli 写作指引、社区规范）。

## 按文档类型的结构

| 类型 | 结构 | 要点 |
|---|---|---|
| 技术方案 | dev-design-solution 的 `solution-template.md` | 评审会通常集体默读 15 分钟再讨论，正文按这个时长控制篇幅，细节放附录 |
| 操作/指导手册 | 适用范围与前置条件 → 步骤 → 预期结果与校验 → 常见问题与回退 | 每步一个动作；命令放代码块并写明环境和版本，示例要实际跑过；步骤里的代码块缩进到该步下面，否则编号会重排 |
| 资料与参考文档 | 概览（回答什么问题、给谁看）→ 按读者的查找路径分节（按对象、按任务或按字母）→ 术语与索引 | 同一对象全文同名；条目格式一致，便于扫读 |

## 通用规则

- **结论先行**：文档开头和每章第一段先说结论，再展开。事实、推断、决定、未知分开写。
- **标题**：用到三级、最多四级，不跳级；同级只有一个的孤立标题合并到上级；不用标题做强调；标题不放进引用或高亮块（放进去不进目录）；不手写目录，飞书左侧自动生成。
- **编号**：标题要么都不写序号，要么统一一套。公文式「一、（一）1.（1）」是一套，「1.」「1.1」「1.1.1」是另一套，不要「一、」下面接「1.1」。
- **段落与句子**：一段一个主题，中心句放段首，一段不超过 7 行；句子超过 40 字就拆。中英文、中文与数字之间加空格，飞书的「文字排版助手」小组件可以一键检查。
- **表格**：只放真正需要比较或对照的信息；不超过 6 列；第一行写表头；少用合并单元格；单元格超过两句话就改用列表或正文。
- **高亮块**：每章最多一个，语义固定：`[!TIP]` 💡 结论或提示，`[!WARNING]` ❗ 风险或限制，`[!IMPORTANT]` 📌 前置条件，`[!NOTE]` 📝 补充说明，`[!CAUTION]` ⛔ 不可逆操作或禁止事项。正式对外的文档少用高亮块和 emoji。
- **颜色**：默认中性色，颜色只表达语义且全文一致；彩色单元格只表示状态或分类。
- **图**：一张图只回答一个问题，图前一句说明、图后写结论；容器选择和 mermaid 写法见 `diagrams.md`。
- **行动项**：写成待办 `- [ ] 事项（负责人，截止日期）`。经 API 写入的 @人不会通知对方，发布后在飞书里 @ 或在评论里提醒。
- **链接**：不要链接本地文件；页内跳转发布后用 `link-plan` 补成标题直达链接。

## 写前检查

`node $S lint --file=<md>` 在本地检查，不需要飞书登录。`publish` 和 `edit` 写飞书前也会自动跑静态规则：错误挡住写入，警告放进 `localWarnings`。

| 级别 | 规则 | 查什么 |
|---|---|---|
| 错误 | `mermaid-unquoted-cjk` | 象限图、XY 图、桑基图里有没加引号的中文（飞书不出图） |
| 错误 | mermaid 语法 | `check_mermaid.js` 用 mermaid 11 解析失败（飞书不出图）；只在 8.13 失败降为警告 |
| 错误 | `public-renderer` | 引用 mermaid.ink、kroki 等公共渲染服务（源码外发） |
| 错误 | `replacement-char` | 有乱码字符 U+FFFD |
| 警告 | `mermaid-all-quoted` | 流程图标签全加了引号（退到画板时失败） |
| 警告 | `sequence-too-large` | 时序图超过 6 个参与者或 20 条消息 |
| 警告 | `heading-skip`、`heading-too-deep`、`heading-numbering-mixed`、`heading-in-callout` | 标题跳级、超过四级、编号体系混用、标题放在引用里 |
| 警告 | `table-too-wide`、`table-long-cell` | 表格超过 6 列、单元格超过两句话 |
| 警告 | `callouts-per-section` | 同一章里多个高亮块 |
| 警告 | `ordered-list-start` | 有序列表不从 1 开始（飞书会从 1 重排） |
| 警告 | `math-dollar`、`local-link`、`html-tag` | 夹着中文的 `$…$` 会变公式、链接指向本地文件、HTML 标签按文字显示 |

mermaid 语法校验需要 `get-browser-session` 装好的 Chrome 与 Playwright，并联网加载 mermaid；缺工具或断网时给出警告和手动命令，其余检查照常。`--out=<目录>` 会在这个目录下新建一个子目录，保存渲染出的 SVG/PNG 和 `results.md`（不覆盖已有文件），`--no-render` 跳过语法校验。警告按需处理：历史文档里的宽表、长单元格可以保留，但要知道飞书上会横向滚动或难读。
